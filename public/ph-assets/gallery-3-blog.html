## The Hidden Cost of "Just Install It"

Every React project starts the same way. You need a date picker. You npm install one. Six months later, the package maintainer disappears, a breaking change lands, and your entire settings page is broken on a Friday afternoon.

This isn't a component quality problem. It's an ownership problem. When your UI depends on someone else's release schedule, you've handed over control of your product's most visible layer.
